# SteamDNA Backend

NestJS-based REST API for the SteamDNA application.

## Features

- Steam OAuth authentication
- JWT-based authorization
- Steam Web API integration
- PostgreSQL database with TypeORM
- Redis for caching
- Swagger API documentation
- Gaming behavior analysis

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build
npm run build

# Run production build
npm run start:prod

# Run tests
npm run test
```

## API Documentation

Visit http://localhost:4000/api/docs when the server is running.
